# Практическая работа №3 — вариант 5

Проект содержит ассемблер и интерпретатор для учебной виртуальной машины
(УВМ). Исходные программы записываются в формате CSV.

## Язык ассемблера

Первая строка файла всегда содержит заголовок:

```csv
mnemonic,b,c,d
```

Каждая следующая строка описывает одну команду. Столбцы `b`, `c`, `d`
соответствуют одноимённым полям спецификации УВМ. Неиспользуемые поля должны
оставаться пустыми.

| Мнемоника | Поля | Действие |
|---|---|---|
| `load_const` | B, C | `memory[B] = C` |
| `read` | B, C, D | `memory[D] = memory[memory[C] + B]` |
| `write` | B, C, D | `memory[memory[C] + D] = memory[B]` |
| `mod` | B, C, D | `memory[C] = memory[memory[D]] % memory[B]` |

Пример:

```csv
mnemonic,b,c,d
load_const,541,480,
read,162,986,494
write,894,643,71
mod,860,700,606
```

## Этап 1. Промежуточное представление

Запуск ассемблера в тестовом режиме:

```bash
./scripts/run_stage1.sh
```

Прямой запуск:

```bash
python3 -m src.assembler SOURCE.csv OUTPUT.bin --test
```

На первом этапе приложение читает CSV, проверяет мнемоники и диапазоны полей,
а затем выводит внутреннее представление в формате `A=..., B=...`.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Проект использует только стандартную библиотеку Python 3.10 или новее.
