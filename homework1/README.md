# Домашняя работа №1 — вариант 5

Инструмент командной строки преобразует учебный конфигурационный язык в
TOML. Исходный текст читается из стандартного ввода, результат выводится в
стандартный вывод, а сообщения об ошибках — в поток ошибок.

Для синтаксического анализа используется специализированная библиотека
[Lark](https://github.com/lark-parser/lark).

## Установка

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

## Запуск

```bash
./run.sh < examples/web_server.conf
```

## Тесты

```bash
./.venv/bin/python -m unittest discover -s tests -v
```

## Синтаксис языка

Допустимое имя начинается со строчной латинской буквы и содержит только
строчные буквы, цифры и `_`:

```text
[a-z][a-z0-9_]*
```

Поддерживаются целые числа со знаком, словари любой глубины, многострочные
комментарии, глобальные объявления и ссылки на константы:

```text
%{
Многострочный комментарий
%}

global port = 8080
global server = dict(
    listen = $[port],
    database = dict(
        host_id = 12,
        pool_size = 5,
    ),
)
```

Словари преобразуются в таблицы TOML. Ссылки `$[имя]` вычисляются во время
трансляции. Поддерживаются ссылки на числа и целые словари, в том числе ссылки
на константы, объявленные ниже по тексту. Неизвестные имена, повторные
объявления и циклические ссылки считаются ошибками.

## Структура программы

- `src/grammar.lark` — формальная грамматика языка;
- `src/parser.py` — запуск Lark и построение синтаксического дерева;
- `src/resolver.py` — вычисление ссылок на глобальные константы;
- `src/toml_writer.py` — формирование таблиц TOML;
- `src/main.py` — чтение stdin, вывод stdout и обработка ошибок.

Параметры командной строки отсутствуют. Это сделано намеренно: согласно
заданию вход передаётся через stdin, а результат получается через stdout.
