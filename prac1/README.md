# Эмулятор командной оболочки — вариант 5

Учебный консольный эмулятор UNIX-подобной командной оболочки.

## Этап 1. REPL

На первом этапе реализованы:

- интерактивный консольный режим;
- приглашение из имени пользователя, имени компьютера и текущего каталога;
- разбор аргументов в кавычках;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- сообщения о неизвестных командах и неверных аргументах.

## Этап 2. Конфигурация

Эмулятор принимает параметры `--vfs` и `--script`. Перед запуском он выводит
полученную конфигурацию. Команды стартового скрипта отображаются вместе с
результатами. При первой ошибке выполнение скрипта прекращается.

## Этап 3. VFS

Источником VFS служит директория на диске. Во время запуска её структура и
содержимое файлов рекурсивно копируются в объекты Python. После загрузки VFS
не обращается к исходным файлам и не изменяет их. Символические ссылки и
специальные файлы намеренно отклоняются.

Для проверки подготовлены три структуры:

- `examples/vfs_minimal` — один файл;
- `examples/vfs_multiple` — несколько файлов и каталог;
- `examples/vfs_nested` — не менее трёх уровней вложенности.

На этапах 1–3 команды `ls` и `cd` остаются заглушками согласно заданию.
Работа с настоящей логикой этих команд относится к этапу 4.

## Запуск

```bash
./run.sh --vfs examples/vfs_nested --script examples/startup_success.txt
```

Готовые сценарии запуска находятся в каталоге `scripts`:

```bash
./scripts/run_with_all_options.sh
./scripts/run_with_error.sh
./scripts/run_minimal_vfs.sh
./scripts/run_multiple_vfs.sh
./scripts/run_nested_vfs.sh
./scripts/run_bad_arguments.sh
./scripts/run_invalid_vfs.sh
```

Сценарии `run_with_error.sh`, `run_bad_arguments.sh` и
`run_invalid_vfs.sh` специально завершаются с ненулевым кодом.

## Структура проекта

```text
practice1/
├── examples/       # стартовые скрипты и тестовые VFS
├── scripts/        # сценарии запуска в Linux
├── src/            # исходный код
├── tests/          # автоматические тесты
├── .gitignore
├── README.md
└── run.sh
```

Для запуска достаточно Python 3.9 или новее. Сторонние библиотеки не нужны.
